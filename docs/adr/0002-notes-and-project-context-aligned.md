# Notes and project-context stay aligned

Search strategy authority is `notes/beauveria-bassiana/`. Agents edit or create under `notes/` only when the user explicitly allows it for that work; otherwise read-only. Notes must remain human-readable without Cursor (no ADR / `.cursor` / skill / `temp/` citations in note body). Always-on `.cursor/rules/project-context.mdc` is a short agent summary with pointers into those notes, not a second scientific record. Both must stay aligned; on conflict, notes win and the rule is corrected to match. Chosen so agents get phase/layout guidance without inventing or forking search design away from Obsidian, while still allowing assisted string and Consensus note updates when requested.
