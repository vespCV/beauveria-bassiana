# Consensus.app is a coverage check, not a parallel review

Before locking database runs, Consensus.app is used only to surface the most important papers per subquestion so categories, research questions, and search strings can be gap-checked against the applied motivation. Asks are delivery-first (_B. bassiana_ with traps, baits, autodissemination, and fluid/protein carriers), entered as natural-language queries in the main Consensus search box ("Ask the research...") with Deep off and no Medical mode or extra Filters, mapped 1:1 to subquestions `01`–`05` with separate asks for `02a`/`02b`/`02c`, and skip `06-background-proxies` unless upstream subquestions keep producing background-only themes. Each ask returns a ranked paper list plus vocabulary (strain codes, product names, delivery terms). Hits are triaged: theme gaps revise questions or categories; missing synonyms/strains/products revise strings; out-of-scope papers are ignored. Subquestion `01` uses Consensus for device/formulation/strain literature and a mandatory parallel pass of EPA, EU Pesticide Database, CABI, and patent sources for the market catalogue. Rejected alternatives: treating Consensus as the systematic corpus or PRISMA evidence; the "Find the Consensus" / Consensus Meter yes-no path with hard efficacy thresholds; social-Hymenoptera-first framing that conflicts with inclusion scope; a Consensus pass for `06` that floods pathogenesis noise; outdated "Copilot/Pro" product labels that are not present on consensus.app.
