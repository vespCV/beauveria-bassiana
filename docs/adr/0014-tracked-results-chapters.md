# Tracked results chapters versus gitignored overview drafts

Publication-facing findings are split: `README.md` stays the short, readable summary of relevant results; numbered chapter pages (plus background and a methods lab journal) live in tracked `results/`; supplementary maps and tables live in `results/attachments/`. Working roll-ups under `temp/overview/` stay gitignored scratch. Chosen so every Zotero annotation can be woven into a chapter without turning the README into a dump, while draft overviews remain session scratch.
