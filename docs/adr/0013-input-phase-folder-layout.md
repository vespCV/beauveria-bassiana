# Input phase folder layout

Replace `search-results/` with phase-aligned input folders: `input-phase0/` (search exports: `input-rayyan/` for Rayyan unduplication, `input-cc-rr/` for CitationChaser and ResearchRabbit seeds), `input-phase1/` (deduplicated records for ASReview/title-abstract screening), and `input-phase2/` (relevant-article list and missing-PDF gate artifacts for full-text/PDF work). Chosen so folder names match the review phase and tool inputs without a nested `raw` / `screening-phase2` split under one catch-all tree.
