# Track raw search exports under search-results/raw

Raw database exports (RIS, PubMed XML, NBIB, CSV, and similar) are stored and tracked under `search-results/raw/` (optionally per-database subfolders) from the first runs. Screening outputs later live under `search-results/screening-phase2/` and related paths. Rejected keeping exports only outside the repo or gitignoring them. Supports methods reproducibility alongside note-based hit-count logging.
